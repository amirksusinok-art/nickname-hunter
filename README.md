# Nickname Hunter — Telegram Mini App

Nickname Hunter — Telegram Mini App (TMA) для охоты за уникальными никнеймами, торговли со скупщиком Авитой, сбора коллекции и соревнований в витринном лидерборде.

- **GitHub репозиторий:** [https://github.com/amirksusinok-art/nickname-hunter](https://github.com/amirksusinok-art/nickname-hunter)
- **Live приложение на Render:** [https://nickname-hunter.onrender.com](https://nickname-hunter.onrender.com)
- **База данных:** Render Managed PostgreSQL 16 (`nickdrop-db`)

## Стек технологий

- **Backend:** Node.js 22+, TypeScript, Fastify 5, Drizzle ORM, PostgreSQL 16 (с поддержкой PGlite для локального запуска без Docker и тестов), криптографическая авторизация TMA HMAC-SHA256.
- **Frontend:** React 19, TypeScript, Vite 6, Tailwind CSS 4, `@telegram-apps/telegram-ui`, `@telegram-apps/sdk-react` / WebApp JS SDK, Lucide Icons, Canvas Confetti.
- **Инфраструктура:** Docker Compose для PostgreSQL 16, Playwright для мобильного TMA аудита.

## Архитектура и ключевые правила

1. **UI-инвариант отображения никнейма:**
   Текст никнейма во всех разделах («Смена», «Коллекция», «Авита», «Лидерборд», «Профиль», карточка шеринга) отображается **исключительно чистым типографическим текстом** без карточек, рамок, плашек, капсул и контейнеров с фоном вокруг текста.

2. **5 разделов (вкладок) Mini App:**
   - **«Смена» (Hunt):** Выбивание никнеймов за 500 UD с прогрессивным Pity-счетчиком (Soft Pity с 10-й попытки, Hard Pity со 100-й попытки), визуализация выпавшего ника, тактильный отклик и модалка шеринга.
   - **«Коллекция» (Collection):** Просмотр инвентаря, фильтрация по тирам редкости, добавление в избранное, разбор дубликатов на UD (с модальным подтверждением), быстрая отправка на оценку к Авите.
   - **«Авита» (Avita):** Интерактивный торговец-скупщик. Оценка по формуле, 4 опции торга (+10%, +125 UD, +50% и согласие), расчет вероятностей согласия/компромисса, запрет повторного торга.
   - **«Лидерборд» (Leaderboard):** Топ-50 витрин игроков с детерминированным тай-брейком (`Score DESC` -> `Rarity DESC` -> `Date ASC` -> `ID ASC`) и сокрытием баланса при приватности.
   - **«Профиль» (Profile):** Статистика игрока, уровень и шкала XP, редчайший трофей, переключатель приватности и режим пониженной анимации.

3. **Экономика:**
   - Стартовый баланс нового игрока: **5 000 UD**.
   - Стоимость стандартной попытки: **500 UD**.
   - Блокировка кнопки выбивания при балансе < 500 UD с отображением точной недостающей суммы.

## Запуск проекта

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
Запуск бэкенда и фронтенда:
```bash
# Терминал 1 (Бэкенд Fastify на порту 3000):
npm run dev:server

# Терминал 2 (Фронтенд Vite на порту 5173):
npm run dev:client
```

Бэкенд автоматически использует PGlite (встроенный Postgres 16) при отсутствии переменной `DATABASE_URL`, либо подключается к PostgreSQL при её указании.

### 3. Запуск PostgreSQL через Docker (опционально)
```bash
docker compose up -d
```
DATABASE_URL для подключения:
`postgres://nickhunter:nickhunter_pass@localhost:5432/nickdrop`

### 4. Тестирование и проверка типов
```bash
# Запуск тестов Vitest (24 теста серверной логики и API):
npm test

# Полная проверка типов TypeScript:
npm run typecheck

# Сборка продакшн бандлов:
npm run build
```
